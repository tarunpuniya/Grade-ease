# Student Grade Management

## Project Objective

Build a Student Grade Management System from scratch without using AI-generated code. The goal is to understand and implement the complete full-stack application development process independently.

In this project, I will design the REST APIs, database structure, backend architecture, frontend architecture, application logic, authentication and authorization, and user interface by myself.

## Project Description

Student Grade is an online academic management platform designed for students and faculty members to manage and access various academic activities in one place.

### Student Features

For students, the platform allows them to:

* Upload assignments
* Access subject notes and study materials
* Pay and manage academic fees
* View upcoming college events and announcements
* Stay updated with college news
* Track their academic performance, marks, and grades

### Faculty Features

For teachers, the platform provides tools to:

* Manage student records
* Upload and manage assignments
* Evaluate student submissions
* Assign and update marks
* Share study materials and announcements
* Monitor the academic performance of individual students

## Technologies Used

### Database

**MongoDB** — for storing student, faculty, assignment, submission, marks, fee, notes, event, announcement, and other application data.

### Backend

**JavaScript with Node.js + Express.js** — for implementing server-side logic, REST APIs, authentication, authorization, and communication between the frontend and database.

### Frontend

**React.js** — for building an interactive, responsive, and component-based user interface for students and faculty.

### Charts & Data Visualization

**Chart.js** — for visualizing academic performance, marks, grades, and other statistical information through charts and graphs.

## Core Architecture

**React.js → Node.js + Express.js → MongoDB**

Chart.js will be integrated into the React frontend to provide visual representations of academic data.
